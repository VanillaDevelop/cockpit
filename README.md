# Cockpit

Cockpit is a web-based dashboard leveraging Flutter as a frontend and Firebase as a backend.
It consists of (as of now) six planned modules that will be gradually released.
The application is deployed on GitHub Pages and uses Google SSO for authentication.

## Module 1: Stream of Consciousness

Stream of Consciousness is a private microblogging application that allows a user to log "thoughts" to one of four categories. A thought starts out as uncategorized, and can (and should) subsequently be moved to one of the remaining three categories. "Actionable thoughts" are thoughts that the user wants to keep track of, to make decisions or take actions based on them in the future. "Actioned thoughts" are thoughts that the user has already acted on. "Fleeting thoughts" are thoughts that do not merit a specific action, but that the user wants to express.
